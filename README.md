# Linux Kullanıcı Hakları ve Yetki Yönetimi (Bash Scripting)

İşletim Sistemleri dersi kapsamında Ubuntu Linux ortamında kullanıcı, grup ve dosya izinlerinin yönetimini otomatikleştiren Bash betiği projesi.

## Özellikler ve Kullanılan Yapılar
- Kullanıcı ve grup sahipliği atamaları (`chown`)
- Dosya ve dizin erişim izinlerinin yapılandırılması (`chmod`)
- Yetkilendirme işlemlerinin ardından sistem durumunun otomatik olarak rapor dosyasına aktarılması

## Çalıştırma
```bash
chmod +x "işletim sistemleri ödev.sh"
./"işletim sistemleri ödev.sh"
```
